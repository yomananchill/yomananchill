### How I work

**Threat model first.** Prior advisories, the bug classes that keep recurring,
the trust boundaries, a short list of invariants that ought to hold.

**One surface at a time.** Never "find all the vulnerabilities". A single
attack surface, read closely. Narrow beats broad; a wide net catches noise.

**Prove it or drop it.** Exact call chain, a reproduction, a patch that
actually closes it. Maintainers get enough plausible-looking noise already.
